# Start here

1. Read [README.md](README.md) (one screen).
2. [DRY.md](DRY.md) — do not copy Host/Peer kernels.
3. [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) — what “done” means.
4. Run `pytest` then `python -m cek_hw.cli vectors`.
5. Plug into `cek-host` with [docs/HOST_PLUG.md](docs/HOST_PLUG.md).
6. Gateway first (`HwStore` or Pi + serial). Arduino second.

Law stays in [cek-framework](https://github.com/bitplorer/cek-framework).
